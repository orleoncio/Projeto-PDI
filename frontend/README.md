# Frontend - Apresentação Interativa do Projeto PDI

Este diretório contém a aplicação web para apresentação dos resultados do projeto **"Preprocessing and Optimizer Impact on Image-Based Autoimmune Disease Diagnosis"**.

## 🎯 Proposta do Site

Transformar os experimentos e descobertas do artigo em uma experiência visual e interativa:

1. **Visão Geral & Contexto**:
   - Apresentação do problema (diagnóstico de doenças autoimunes via células HEp-2).
   - Metodologia de replicação do artigo.
2. **Comparador de Pré-processamento**:
   - Comparação visual lado a lado (Imagem original vs Expansão de contraste / Equalização de histograma).
3. **Dashboard de Resultados & Métricas**:
   - Comparativo interativo entre modelos (**VGG-16** vs **SqueezeNet** vs **ResNet-50**).
   - Impacto dos otimizadores (**SGD** vs **Adam**) e a reprodução fiel do colapso do Adam reportado no artigo.
   - Gráficos de acurácia, F1-Score, loss e matrizes de confusão.
4. **Demonstração / Inferência**:
   - Visualização de predições em amostras de teste.
